# Practical Electronics Course

My notes, summaries, and simulations for the **Practical Electronics Course** by Waleed Issa Academy (videos in Arabic).

**Progress: 48 / 100 episodes finished (48%)** · 21 watched · 27 with notes on paper · 0 on GitHub

The foundation course of the diploma: electricity basics, measuring instruments, passive components (R, L, C), switches and relays, diodes, transistors, thyristors, power supplies, the 555 timer, op-amps, filters, and sensors (100 episodes).

**Tools:** Circuit Wizard (Multisim is also introduced in ep16)
