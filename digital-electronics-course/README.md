# Digital Electronics Course

My notes, summaries, and simulations for the **Digital Electronics Course** by Waleed Issa Academy (videos in Arabic).

Number systems, logic gates and logic families (TTL / CMOS), Boolean algebra and Karnaugh maps, combinational circuits, flip-flops, shift registers, counters, DAC / ADC, memory, and programmable logic (37 episodes).

**Tools:** Proteus (introduced in ep03)
